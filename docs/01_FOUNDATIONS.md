# 01 Foundations

## Purpose

이 문서는 `abtest`의 가장 기본이 되는 실험 철학, 통계 기초, 실험 설계 입문 내용을 묶어 둔 시작 문서다.

## Covers

- randomized A/B와 cohort-based comparative experiment의 차이
- p-value, confidence interval, bootstrap 같은 통계 기초
- MDE, sample size, test duration, stopping rule의 기본 감각

## Key Takeaways

- 현재 실무 적용은 randomized A/B보다 quasi-experiment에 가깝다.
- p-value 하나로 결론 내리지 않는다.
- 실험 전 MDE, 기간, stopping rule을 먼저 정한다.
- 표본이 부족하면 결정 실험이 아니라 탐색 실험으로 분류한다.
