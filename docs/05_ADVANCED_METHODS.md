# 05 Advanced Methods

## Purpose

이 문서는 기본 실험 해석 위에 올라가는 고급 통계/실험 방법을 묶는다.

## Covers

- ratio / derived metrics
- multiple testing and false discovery
- variance reduction
- sequential / always-valid testing

## Key Takeaways

- 고급 방법은 기본 설계 문제를 고쳐주지 않는다.
- ratio metric은 numerator/denominator를 같이 저장해야 한다.
- multiple testing에서는 family 정의가 핵심이다.
- variance reduction은 estimator의 standard error를 낮춘다.
- sequential은 peeking 현실을 통계 규칙 안으로 가져오는 방법이다.
