# 02 Experiment Policy

## Purpose

이 문서는 실험 플랫폼을 어떤 원칙과 규칙으로 운영할지에 대한 정책 레이어를 묶는다.

## Covers

- 실험 등록 요건과 승인 기준
- 실험 단위와 variant 정의
- 데이터 수집/보관/접근 정책
- 참여자 고지와 보호 원칙
- 결과 공유와 의사결정 반영 절차

## Key Takeaways

- 등록과 승인은 분리한다.
- 기본 실험 단위는 cohort다.
- 필요한 데이터만 수집하고 접근 권한은 최소화한다.
- 참여자 보호와 결과 기록은 실험 성공 여부와 무관하게 적용한다.
