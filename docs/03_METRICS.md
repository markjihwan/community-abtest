# 03 Metrics

## Purpose

이 문서는 어떤 지표를 왜 보고, 어떤 우선순위로 판단에 쓸지 정리한 문서다.

## Covers

- North Star, Supporting KPI, Guardrail, Leading Indicator
- metric 정의와 분모/분자 고정
- 운영용 KPI 우선순위와 최소 세트

## Key Takeaways

- North Star는 완주율 하나로 고정한다.
- Funnel과 Retention은 섞지 않는다.
- Guardrail 없이 primary만 보고 판단하지 않는다.
- leading indicator는 인과가 아니라 조기 신호로 해석한다.
